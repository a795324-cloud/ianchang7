## 三、問題回答

### 問題一：為什麼 `"4"` 要先轉成數字，才能用於本題的分攤計算？
在 Python 中，加上引號的 `"4"` 是**字串（`str`）**型別，代表的是「文字字元」而非數學上的數量。電腦無法直接將數字（例如應付總額 `1220.0`）除以文字 `"4"`，若直接執行 `1220.0 / "4"` 會觸發 `TypeError` 錯誤。因此，必須先使用 `int("4")` 將其轉換為**整數（`int`）**型別，才能進行除法運算來計算每人分攤費用。

### 問題二：如果先扣折價券，再依剩餘餐費計算服務費，第一組的應付總額會變成多少？為什麼和題目規定的結果不同？
* **計算過程：**
  1. 先扣折價券：$1200 - 100 = 1100$ 元
  2. 再算 10% 服務費：$1100 \times 0.10 = 110$ 元
  3. 應付總額：$1100 + 110 = 1210$ 元
* **結果差異原因：**
  若先扣折價券再算服務費，應付總額會變成 **1,210 元**，比題目規定的 **1,220 元**少了 10 元。這是因為計算基準（母數）不同：題目規定服務費必須以「原始餐費（1,200 元）」計算，因此折價券的 100 元也需要被收取 10% 服務費（$100 \times 0.10 = 10$ 元）；若先扣除折價券，這 100 元就沒有被計算到服務費，導致總金額產生 10 元的落差。
